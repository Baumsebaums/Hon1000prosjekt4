"# Hon1000prosjekt4" 
For å kjøre denne filen trenger man å laste ned java: det kan gjøres fra https://www.java.com/download/manual.jsp

Deretter som må man oppne Command prompt, dretteter så må man orientere seg til filplaseringen hvor man har lasted ned Pseudo3D.java, i Command prompt, dette kan gjøres ved å bruke kommandoen cd. 

Når en er der inne skriver man javac Pseudo3D for å komplilere filen. Også skriver man java Pseudo3D.java
